# Abstract

Quadrotors are highly coupled dynamical systems whose motion is influenced by multiple control inputs and physical states such as position, velocity, orientation, and angular velocity. Developing a complete analytical model of a quadrotor can be challenging because of the nonlinear interactions between its states, actuators, and physical parameters. Data-driven system identification provides an alternative approach in which the system dynamics are learned directly from observed state and control-input data.

This project investigates **Drone System Identification using Dynamic Mode Decomposition with Control (DMDc)**. The objective is to obtain an approximate mathematical representation of quadrotor dynamics directly from flight or simulation data. The common identification framework is based on the discrete-time state-space model

\[
x_{k+1}=Ax_k+Bu_k,
\]

where \(x_k\) represents the current system state, \(u_k\) represents the applied control input, \(A\) represents the identified state-transition dynamics, and \(B\) represents the influence of the control inputs on the system.

Three different environments are considered for generating quadrotor data: **Gym-PyBullet, MuJoCo, and ArduPilot**. Each implementation uses its own simulation or flight-data-generation mechanism and may use a different state representation depending on the available measurements and modelling objective. The Gym-PyBullet implementation uses programmatic PID-based control to generate quadrotor trajectories and records position, velocity, and motor-input information. The MuJoCo implementation uses manually commanded movements through a control interface, with the resulting quadrotor states and applied motor inputs recorded for identification. The ArduPilot implementation uses Software-In-The-Loop (SITL) flight data and extracts relevant attitude, angular-rate, and motor-output information from flight logs.

The collected data is organized into snapshot matrices \(X\), \(X'\), and \(U\), where \(X\) contains current states, \(X'\) contains corresponding next states, and \(U\) contains control inputs. DMDc uses Singular Value Decomposition (SVD) on the combined state-input data to estimate the matrices \(A\) and \(B\). The resulting model can then be used to predict the future behaviour of the quadrotor for a given sequence of control inputs.

The project therefore provides a common data-driven modelling framework while allowing the same methodology to be investigated across multiple quadrotor simulation and flight-data environments.

# 1. Introduction

## 1.1 Background

Quadrotors, commonly known as quadcopters or drones, are aerial robotic systems consisting of four rotors arranged around a rigid body. By varying the thrust generated by the individual rotors, a quadrotor can control its vertical motion, horizontal motion, and orientation.

Quadrotors are used extensively in:

- Aerial robotics
- Autonomous navigation
- Surveillance
- Inspection
- Mapping
- Delivery systems
- Search and rescue
- Research and education
- Control-system development

The dynamics of a quadrotor are coupled and nonlinear. A change in the speed of one or more motors can affect several aspects of the vehicle's motion simultaneously.

For example, changing the motor speeds can influence:

- Vertical thrust
- Roll
- Pitch
- Yaw
- Position
- Linear velocity
- Angular velocity

Therefore, obtaining a mathematical model that accurately describes the behaviour of the vehicle is an important step in quadrotor analysis and control.

---

## 1.2 Analytical Modelling vs Data-Driven Modelling

A conventional approach to modelling a quadrotor is to derive its equations of motion from physical laws.

Such a model may require knowledge of:

- Mass
- Moments of inertia
- Gravity
- Rotor geometry
- Thrust coefficients
- Drag coefficients
- Motor characteristics
- Aerodynamic effects

Although analytical modelling provides valuable physical insight, developing a sufficiently accurate model can become complicated.

An alternative is **system identification**.

System identification attempts to learn an approximate model directly from observations of the system.

The general idea is:

\[
\text{Control Input}
\rightarrow
\text{Quadrotor}
\rightarrow
\text{Measured State}
\]

By collecting a large number of such observations, the relationship between the control inputs and the resulting state changes can be learned.

# 2. Project Objective

The main objective of this project is to investigate a **data-driven approach for identifying quadrotor dynamics using Dynamic Mode Decomposition with Control (DMDc)**.

The major objectives are:

1. Generate quadrotor flight data.
2. Apply control inputs to the simulated or virtual quadrotor.
3. Record the resulting system states.
4. Organize the data into state and control snapshots.
5. Construct \(X\), \(X'\), and \(U\).
6. Apply Singular Value Decomposition (SVD).
7. Use DMDc to identify the matrices \(A\) and \(B\).
8. Construct an approximate discrete-time state-space model.
9. Use the learned model to predict future system states.
10. Compare predicted behaviour with actual system behaviour.
11. Investigate the quality and limitations of the identified model.
12. Apply the common methodology across different simulation environments.
